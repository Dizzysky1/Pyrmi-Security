Bot and tamper detection
for your site. One script tag.

Pyrmi spots bots, scrapers, replayed requests and tampered pages in the browser. Your server asks for a verdict before it trusts a sign-up, a vote, a checkout or a score, and the dashboard shows every flag and why.

// how it works

1

Add the script

Each visit gets a signed session from a real page load. The script watches for automation, scripted input, replaced browser functions, devtools and clock tricks.

2

Check on your server

Before you act on a request, call pyrmi.verify(). You get accept, review or reject, a risk score from 0 to 100, and the reasons.

3

Watch it work

The dashboard shows every verdict, which checks fired, and which users keep getting flagged, so you see how well it's working instead of a yes or no.

on your server 
const { Pyrmi, trusted } = require('pyrmi-server');
const pyrmi = new Pyrmi({ secretKey: process.env.PYRMI_SECRET_KEY });

const v = await pyrmi.verify({ sealed: req.body, req, user: email });
if (v.verdict === 'reject') return res.status(403).end(); // a sign-up: a review goes through, flagged
// a payout or a prize instead: if (!trusted(v)) return res.status(403).end();

// what it catches

Bots and headless browsersWebdriver flags, headless Chrome, Playwright, Puppeteer, Selenium and Cypress markers.
Scrapers and direct API callsA request with no signed session from a real page, or a session that never reported from one, gets flagged.
Replayed requestsEach session token works once and expires. Sending the same request twice fails.
Forged or edited tokensSessions are signed on the server. Change one byte and the verdict is reject.
Tampered pagesReplaced fetch, performance.now, requestAnimationFrame and other built-ins.
DevtoolsAn open devtools panel is noted on the session, so you can weigh it with everything else.
Scripted inputSynthetic events and typing or clicking that's too even or too fast for a human hand.
Impossible valuesActions sent faster than a person could, numbers past your caps, or values that grow too fast.
What it won't doBlock devtools or "stop code running". Whoever owns the browser can switch any of that off. Pyrmi watches and reports, and your server has the final say.

- 2026-10-31: Round 6 anti-tamper (branch pyrmi-round6). The replaced built-ins check no longer trusts a `[native code]` match in `toString` (a `.bind()` or `Proxy` wrapper printed that too, so `performance.now = (() => 0).bind(window)` read as clean and verified at risk 0). It now compares each watched built-in by identity with a reference taken at load, and against a clean copy from a hidden iframe (how it prints, which must include its own name, and where it lives), with a bound-name stopgap. It also checks `Function.prototype.toString`/`call`/`apply`/`bind`, `Object.getOwnPropertyDescriptor`/`getPrototypeOf`, `createElement`, the iframe `contentWindow` getter and the navigator `webdriver`/`userAgent`/`languages` getters (stealth patches); the script's own clocks, timers, fetch and listeners use the load-time references and `window.Pyrmi` is frozen. SDK 1.2.0. Deferred items are in docs/HARDENING-TODO.md.
- 2026-10-31: Round 6, part 2. Changes to the built-ins error trackers and frameworks wrap on ordinary sites (timers, rAF, fetch, XHR send, addEventListener, toString: Sentry, zone.js/Angular, Datadog, New Relic) are now `wrapped_runtime` (+5) instead of `tampered_runtime` (+30); the split is by built-in, never by library markers, so the clocks, Math.random, call/apply/bind and the navigator getters stay at full weight. Added `/sdk/selftest.html`, which runs every trick in a real browser and shows what it reports (for checking Safari and Firefox by hand).
- 2026-10-31: Round 7 (branch pyrmi-round7). Hand-written telemetry no longer earns a clean verdict: each beacon is checked against what the server saw itself (the page that started the session, browser fetch headers, the page clock against the server's from session start, counters that only grow, a per-session beacon nonce and count), failures add `unverified_client` (+40), and a beacon with no fingerprint or fields is `tampered_runtime`. Old build fingerprints expire after a grace period; the readable source's isn't accepted in production. Browser script 1.3.0: replaces a planted `window.Pyrmi`, catches input hidden from it via `navigator.userActivation`, counts more scripted events, reads the devtools hint through load-time getters. Removed DRAFTS.md (stale notes about the old site).
